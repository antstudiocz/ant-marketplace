# 13.1.2 — Autonomous implementation authority

- Keeps user-authorized implementation work moving across phases, interruptions, agents, repair, review and checks while asking only for consequential missing human intent or out-of-scope impact.
- Makes native Codex Goals optional unless explicitly requested or already in use; missing optional Goal support does not block authorized work, while an explicit Goal request remains pending until verified.
- Clarifies scoped PR/MR Create/update delivery for already agreed repositories and targets, with merge, release and deployment authority remaining separate.

Instruction-only patch; no runtime migration is needed.
