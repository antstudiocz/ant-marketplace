# 12.1.1

Version 12.1.1 is a compatible instruction-only patch release.

## Changes

- Clarifies that required child and nested-child route selection and dispatch are automatic internal execution under established implementation authority, not separate user approval or confirmation gates.
- Preserves genuine host-native approval semantics and fail-closed behavior when a required route or selector is unavailable or unenforceable.

No runtime migration, orchestration database, or global helper installation is required.
