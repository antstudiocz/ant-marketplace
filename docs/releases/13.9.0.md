# 13.9.0 — Deep research workflow

Adds an instruction-only skill for broad, read-only investigation of codebases,
architecture, and incidents. It coordinates independent specialist views around
a shared evidence baseline, checks material claims against appropriate source
or runtime evidence, and reports uncertainty, alternatives, and next steps.
Research stays separate from implementation and does not authorize system
changes. Performance, resource, and scale benefits require reproducible
measurements; synthetic results apply only to their measured conditions, and
production projections are labeled estimates. No runtime benchmarks were run
for this release.
