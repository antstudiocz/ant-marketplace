# 13.4.0 — Simplicity review for implementation

## Improvements

- Applies a simplest complete design standard to target-project implementation for verified current requirements, with reuse of existing mechanisms and concrete justification for significant new layers, abstractions, dependencies, configuration, or generality.
- Reconsiders architecture when complexity grows materially and gathers proportionate early evidence that the core path works end to end and integrates before deep support-subsystem polishing.
- Requires both the implementer and independent reviewer to perform a pre-freeze simplicity review covering unnecessary layers, duplicate state, unjustified genericity, and tests without meaningful unique coverage; material safe simplifications are implemented and reverified within scope.

## Internal changes

- Keeps simplicity and architecture policy canonical in the shared lifecycle and routes the skill entrypoint and public documentation to it.

Instruction-only compatible minor release; no target-project code, runtime, new public skill, synthetic evaluation framework, or host behavior change is included.
