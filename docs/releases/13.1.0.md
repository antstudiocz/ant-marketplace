# 13.1.0

Version 13.1.0 is a compatible instruction-only minor release.

## Changes

- Shortens the canonical orchestration guidance while keeping repository ownership, durable-plan, routing, review, validation, and delivery safeguards in their designated references.
- Makes Codex native Goals default-on when available and authorized, with a truthful durable-plan fallback for an optional absent or unavailable Goal. Explicit Goal requirements remain unmet until a matching Goal is verified, and fallback does not promise automatic continuation.
- Adds asynchronous clarification handling and scopes material questions to the affected work. Optional preferences may proceed after a stated reasonable assumption; required decisions and approvals remain pending until answered.
- Defines endpoint-aware completion for implementation-only, draft PR/MR, and explicitly merge-ready work, including current-head, conflict, review, and required CI/provider-gate evidence for merge-ready completion.
- Standardizes PR/MR descriptions around four substantive sections: Summary, Rationale, Impact/risk, and Verification. Descriptions are rebuilt from the final target merge-base-to-`HEAD` snapshot and keep failures and gaps visible.
- Clarifies ordinary internal delegation as execution under established authority, avoiding duplicate consent requests, while requiring independent cross-thread handoffs to preserve and verify consent provenance, scope bounds, and the exact follow-up.
- Aligns completion reporting and installation documentation with the requested endpoint, evidence, gaps, and next permitted action, including current Codex marketplace and desktop installation paths.

No runtime migration, orchestration database, hook, permission bypass, compatibility shim, or global helper installation is required. Follow the current [installation and updates guide](../install.md), then restart or reload the host as directed.
