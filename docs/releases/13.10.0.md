# 13.10.0 — Independent plan and architecture review

A user can select a review workflow for an implementation run, optionally with
an independent plan review. Work affected by that review waits for it, and
material plan repairs receive a focused confirmation. The final review covers
architecture and code quality more broadly across the whole outcome. Team model
routes are used only after verification, and defaults remain portable. Plan
review is not human approval and grants no authority.

No post-deployment actions are required. To receive the update, follow the
standard marketplace update steps in [Installation and updates](../install.md).
