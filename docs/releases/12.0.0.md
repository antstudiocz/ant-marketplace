# 12.0.0

Version 12.0.0 is a clean breaking redesign of the `(ant)` marketplace.

## Changes

- Consolidates the plugin to three public entry points for implementation orchestration, PR/MR delivery plus conflict resolution, and brand design.
- Keeps shared strong/balanced/fast capability routing host-neutral while restoring explicit host execution policy: Claude `best` + Max root with five bounded Opus/Sonnet child profiles, including `ant:fast` at Sonnet Low, and Codex Sol High root with explicit Sol/Luna child routes and fresh context.
- Adds a fail-closed Claude override preflight for current subagent-model resolution, exact fixed effort, observable allowlists/caps, and actual-runtime mismatch recovery.
- Makes Codex Goal objectives immutable while treating Claude native goal support as optional.
- Adds concise new-application intake to the orchestrator and removes compatibility paths for the superseded skill architecture.
- Simplifies delivery descriptions around a final-diff human-first template and adds conflict-only authority safeguards.
- Preserves the complete bundled brand asset set with one canonical source manual and corrected image paths.

## v11 → v12 migration and retirement

| v11 entry point | v12 path | Status |
|---|---|---|
| `create-application` | `implementation-orchestrator` new-application intake | Retired; use the orchestrator's intake and Plan. |
| `delivery-workflows` | `merge-request` conflict-resolution mode | Retired; use the merge-request skill. |
| Frontend and Laravel skills | Current repository/host domain guidance | Retired; no replacement aliases or shims. |
| Google Docs and Asana skills | Host connectors or provided source content feeding a current skill | Retired; no replacement aliases or shims. |

Existing callers must switch to one of the three current public skills; no aliases or forwarding shims are provided.
