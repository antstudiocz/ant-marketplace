# 13.5.1 — Compact delegated consent context

## Fixed

- Preserves a compact delegated authorization context through child assignments and independent handoffs, carrying relevant consent, source/reference when available, approved scope and bounds, exact follow-up, and any proposed scope delta.
- Keeps that context concise without retrieving or copying full conversation history by default, and requires blocker handling to ask only for a specific missing authority when established consent does not cover the requested effects.

Existing host safety boundaries still apply: a denied operation cannot be bypassed or disguised, and preserved authorization context cannot guarantee acceptance by automatic review.
