# 13.3.0 — Publish-ready PR/MR release notes

## New features

- Adds a parser-ready `## Release notes` section to PR/MR descriptions with exact `New features`, `Improvements`, `Fixes`, and `Internal changes` categories.
- Supports the exact `No release impact.` sentinel when a change has no user-facing release impact.

## Improvements

- Keeps practical user and technical impact, compatibility or rollout risk, safeguards, and material verification gaps visible before release notes.
- Moves implementation context and detailed verification into collapsible sections so concise release entries are ready to publish.

## Internal changes

- Refreshes release notes from the final target merge-base-to-`HEAD` snapshot and links the merged change during authorized release publication.
