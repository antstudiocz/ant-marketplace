# 13.9.4 — Clearer PR/MR descriptions

PR and MR descriptions now lead with concise, flat summaries and practical risks,
then keep functional evidence and complete operator steps in technical details.
Real application captures use captioned lists before release notes; collapsed
groups depend on verified consumer compatibility. A proportionate description
review is part of the existing whole-outcome review. Transient CI and delivery
state stays in the readiness report. The update adds no runtime or mandatory
test gate.

No post-deployment actions are required. To receive the update, follow the
standard marketplace update steps in [Installation and updates](../install.md).
