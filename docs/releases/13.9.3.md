# 13.9.3 — Value-first test cleanup guidance

The shared test quality policy distinguishes mechanical test optimizations, which
preserve meaningful scenarios and their oracles, from authorized cleanup that
may remove valueless cases or redesign a suite while retaining important
behavioral contracts. It adds optional, temporary fault-sensitivity checks for
important rewritten tests and requires performance claims to match measured
evidence. This instruction-only update adds no runtime or mandatory test gate
and makes no measured speed claim.

No post-deployment actions are required. To receive the update, follow the
standard marketplace update steps in [Installation and updates](../install.md).
