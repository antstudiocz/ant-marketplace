# 12.1.0

Version 12.1.0 is a compatible instruction-only minor release.

## Changes

- Makes the host-native Plan the single live, user-visible TODO checklist throughout orchestrated execution, with concise phase and progress updates as work advances and recovers.
- Provides more durable visibility of pending work, current progress, and completed evidence without introducing custom TODO persistence or runtime state.
- Keeps native Goal behavior separate: Goal tracks the matching objective, while Plan remains the live TODO view.

No runtime migration, orchestration database, or global helper installation is required.
