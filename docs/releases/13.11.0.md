# 13.11.0 — Marketplace release skill

Adds the public
[`ant-marketplace-release`](../../plugins/ant/skills/ant-marketplace-release/SKILL.md)
skill. Maintainers can preview a release of this marketplace without
external effects. The preview covers synchronized versions, every merged PR
since the previous release, notes, and a Czech Google Chat card. GitHub writes
follow the existing `merge-request` workflow under the user's authority. A Chat
announcement is sent only through a verified route, after the user explicitly
approves the destination and the exact content. Organization configuration may
establish an available route, but it is not permission to send on its own.

No post-deployment actions are required. To receive the update, follow the
standard marketplace update steps in [Installation and updates](../install.md).
