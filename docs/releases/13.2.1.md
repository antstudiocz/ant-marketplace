# 13.2.1 — Clearer blocker adjudication

- Distinguishes ordinary reviewer findings and child uncertainty from capability errors, timeouts, and explicit host or tool safety denials.
- Preserves existing consent and verifiable scope references across child context and handoffs without routine redundant questionnaires.
- Clarifies coherent assignment ownership and internal escalation when a discovered dependency crosses an assignment boundary.
- Documents Codex parent communication through native collaboration messaging or the child final response, reserving thread messaging for verified independent handoffs.
- Keeps host safety permissions intact: a denied operation cannot be routed through another agent or tool, while unrelated authorized work can continue.

No runtime migration, hook, permission change, or public skill change is required.
